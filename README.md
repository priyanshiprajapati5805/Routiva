# Routivaa 🚗

### Smart Ride Sharing Platform

Routivaa is a ride-sharing platform designed to connect drivers and passengers, making daily travel more affordable, convenient, and reliable.

## 🌟 Features

- User Registration and Login
- Search Available Rides
- Book Rides
- Driver and Passenger Management
- Ride Booking Management
- Ride Subscription Plans
- User-Friendly Interface
- Backend API Integration

## 🛠️ Technology Stack

**Frontend**
- HTML
- CSS
- JavaScript

**Backend**
- Java
- Spring Boot

**Database**
- MySQL

**Development Tools**
- Visual Studio Code
- IntelliJ IDEA
- MySQL Workbench
- Git & GitHub

## 🚀 Project Objective

The main objective of Routivaa is to provide a convenient ride-sharing solution that helps passengers find rides and allows drivers to share available seats.
